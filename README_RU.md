# Target Overlay MVP


## Автоматическая сборка APK через GitHub (без Android Studio)

В проект добавлен workflow `.github/workflows/build-apk.yml`.

1. Создай репозиторий на https://github.com (кнопка **New repository**).
2. Назови его, например, `TargetOverlay`, и создай репозиторий.
3. Распакуй этот ZIP на телефоне/планшете.
4. На странице репозитория нажми **Add file → Upload files** и загрузи содержимое папки проекта. Важно: загружай сами папки и файлы проекта, а не ZIP-архив целиком. Сохрани структуру, включая скрытую папку `.github/workflows`.
5. Нажми **Commit changes**.
6. Открой вкладку **Actions** в репозитории. Должен запуститься workflow **Build Android APK**.
7. Когда сборка завершится со статусом зелёной галочки, открой её запуск, найди раздел **Artifacts** и скачай `TargetOverlay-debug-APK`.
8. Распакуй скачанный архив и установи `app-debug.apk`. Android может попросить разрешить установку приложений из этого источника.

Если автоматический запуск после загрузки файлов не начался: **Actions → Build Android APK → Run workflow**.

Важно:
- Это debug APK для установки и проверки, не публикационная release-сборка.
- Первая версия исходников пока не проходила реальную компиляцию и тестирование. Если GitHub покажет ошибку сборки, пришли сюда скриншот или текст ошибки — разберём и поправим.
- Не загружай в публичный репозиторий личные ключи, пароли или другие секреты. Для этого проекта они не нужны.
